# 使用者人物誌法則

## 核心價值

使用者人物誌將分散的研究資料轉化為具象的角色原型,讓團隊能快速對齊目標使用者的需求、動機與行為模式。有效的人物誌不是虛構故事,而是基於真實資料的決策工具,幫助團隊在設計過程中持續聚焦使用者價值。

## 適用情境

- 完成使用者研究後,需要整合洞察時
- 團隊需要對目標使用者有共同理解時
- 做設計決策時需要參考依據
- 向利害關係人溝通使用者需求時

## 輸入資訊

- 使用者訪談或研究資料
- 問卷、行為數據或客服回饋
- 目標產品與情境範圍
- 團隊目前的設計問題或決策需求
- 需要定義的人物誌數量與用途

## 預期產出

- 使用者分群邏輯
- Persona 草案與關鍵欄位
- 目標、痛點與行為模式摘要
- 可溝通的角色描述文件
- 後續設計應用建議

## 觸發提示

- 使用者提到「persona」、「人物誌」、「使用者角色」、「目標族群」、「使用者分群」
- 任務需要把研究資料轉成具體角色模型
- 任務需要讓團隊對設計對象建立一致認知

## 複雜情境觸發提示

- 任務涉及 B2B 產品、後台工具、管理平台或跨部門服務流程
- 使用者提到多種角色使用同一系統,但目標、權限或操作頻率差異很大
- 任務需要區分決策者、管理者、執行者、審核者或支援人員的不同需求
- 團隊對「誰是主要使用者」沒有共識,需要先建立角色優先順序

## 先問哪些澄清問題

- 這個產品或流程中有哪些核心角色?誰是主要使用者,誰是次要角色?
- 每個角色的主要任務、成功指標與最在意的風險是什麼?
- 角色之間是否有交接、審批、覆核或資料移轉的關係?
- 不同角色使用的頻率、裝置、情境與技術能力是否不同?
- 現有研究資料是否足夠支撐角色區分?哪些角色仍然缺乏證據?
- 這次人物誌要用於什麼決策?例如流程設計、功能優先序、教育訓練或導入策略

## 可搭配哪些其他 skill

- `user-interview`: 先補齊不同角色的第一手研究資料
- `information-architecture`: 根據不同角色的心智模型設計內容與導航
- `prototyping`: 為不同角色建立關鍵流程原型
- `usability-testing`: 驗證不同角色是否能順利完成任務

## 複雜需求範例

### B2B CRM 平台

- 情境: 同一套 CRM 由業務、業務主管與營運分析師共同使用
- Persona 重點: 區分「高頻操作的業務」與「看報表決策的主管」在任務、資訊需求與時間壓力上的差異

### 後台客服工單系統

- 情境: 客服專員、資深客服與主管都會進入同一後台,但處理範圍不同
- Persona 重點: 找出權限差異、例外工單處理方式與不同經驗層級的訓練需求

### 多角色供應鏈流程

- 情境: 採購、倉管、財務與主管共同參與請購到付款流程
- Persona 重點: 釐清每個角色的 KPI、依賴資訊、常見錯誤與跨部門等待成本

## 工作流程

### 1. 收集資料

**整合研究資料**
- 訪談記錄
- 問卷調查結果
- 使用者行為分析數據
- 客服反饋
- 市場研究報告

**資料來源檢查清單**
```markdown
□ 使用者訪談逐字稿
□ 問卷調查數據
□ 網站/App 分析數據
□ 客服紀錄
□ 社群媒體反饋
□ 競品使用者研究
```

### 2. 識別模式

**分析使用者特徵**
- 人口統計資料(年齡、性別、職業、收入)
- 行為模式(使用頻率、使用情境、偏好管道)
- 目標與動機(想達成什麼、為什麼使用產品)
- 痛點與挫折(遇到什麼問題、什麼讓他們困擾)
- 技術能力(數位素養、使用的裝置)

**使用親和圖法整理**
```markdown
1. 將每個使用者的特徵寫在便利貼上
2. 將相似的特徵分組
3. 為每組命名主題
4. 識別出 3-5 個主要群體
```

### 3. 分群歸類

**建立使用者區隔**
- 根據目標、行為、痛點的相似性分組
- 確保每個群體有明顯差異
- 優先處理最重要的使用者群體

**區隔矩陣範例**
```
         | 高技術能力 | 低技術能力
---------|-----------|------------
高頻使用  | 專業玩家   | 忠實粉絲
低頻使用  | 偶爾嘗試   | 新手小白
```

### 4. 創建人物誌

**人物誌必備元素**

```markdown
# 人物誌名稱: [給一個記憶點的名字]

## 基本資訊
- **照片**: [使用真實感的照片]
- **年齡**: XX 歲
- **職業**: [具體職稱]
- **地點**: [居住城市]
- **家庭狀況**: [婚姻、子女]

## 個人簡介
[2-3 句話描述這個人的生活方式和個性]

## 目標
1. [主要目標]
2. [次要目標]
3. [長期願景]

## 痛點
1. [最大的挫折]
2. [日常困擾]
3. [未被滿足的需求]

## 行為模式
- **使用頻率**: [每天/每週/每月]
- **偏好裝置**: [手機/電腦/平板]
- **使用情境**: [何時何地使用]
- **資訊來源**: [如何發現新產品]

## 引言
「[真實受訪者的代表性引言]」

## 技術能力
[評分: ⭐⭐⭐☆☆]

## 使用情境故事
[描述一個典型的使用情境]
```

### 5. 驗證調整

**驗證人物誌**
- 與團隊成員討論是否符合實際觀察
- 與真實使用者確認是否有共鳴
- 確保基於資料而非假設

## 流程檢查清單

使用此清單確保人物誌創建流程完整執行:

### 資料收集階段 ✓
- [ ] 已整合至少 5-8 份訪談或問卷資料
- [ ] 已收集使用者的目標、行為、痛點資訊
- [ ] 已記錄真實的使用者引言
- [ ] 已了解使用者的使用情境與頻率

### 分析分群階段 ✓
- [ ] 已識別 3-5 個主要使用者模式
- [ ] 已將相似使用者歸為同一群體
- [ ] 已確認每個群體的代表性
- [ ] 已驗證分群邏輯與團隊達成共識

### 創建階段 ✓
- [ ] 已為每個群體創建 1 個代表性人物誌
- [ ] 人物誌包含基本資訊、目標、痛點、行為模式
- [ ] 已加入真實引言增加可信度
- [ ] 已描述典型使用情境故事
- [ ] 總共創建 3-5 個主要人物誌

### 驗證階段 ✓
- [ ] 已與團隊成員驗證人物誌準確性
- [ ] 已確認基於真實資料而非假設
- [ ] 已獲得利害關係人認可
- [ ] 已建立人物誌更新機制

**持續更新**
- 定期檢視人物誌是否仍然準確
- 根據新的研究發現更新
- 隨著產品演進調整

## 快速執行指南

**2 小時快速版**
1. 整理現有研究資料 (30 分鐘)
2. 識別 2-3 個主要使用者群體 (30 分鐘)
3. 創建簡化版人物誌 (基本資訊+目標+痛點) (40 分鐘)
4. 團隊驗證與調整 (20 分鐘)

**完整版 (建議)**
1. 收集並整合研究資料 (2-4 小時)
2. 分析並識別使用者模式 (3-4 小時)
3. 分群並確認代表性 (2 小時)
4. 創建 3-5 個完整人物誌 (4-6 小時)
5. 驗證與調整 (2 小時)
6. 設計視覺化呈現 (2 小時)

**決策樹: 何時使用哪個版本?**
- 已有充足研究資料 + 需要快速對齊 → 快速版
- 新產品或重大改版 → 完整版
- 多個利害關係人需要說服 → 完整版 + 視覺化

## 最佳實踐

1. **基於真實資料**: 基於真實資料而非假設創建
2. **適量即可**: 通常創建 3-5 個主要人物誌即可
3. **具體明確**: 包含具體的目標、動機和痛點
4. **真實引言**: 加入真實的引言增加可信度
5. **定期更新**: 定期更新以反映使用者變化
6. **避免刻板印象**: 避免刻板印象和過度簡化
7. **團隊共識**: 確保團隊成員都理解並認同人物誌

## 範例輸出

```markdown
# 精打細算的小資族 - 王小美

## 基本資訊
- **年齡**: 28 歲
- **職業**: 行政助理
- **地點**: 台北市
- **收入**: 月薪 35,000 元
- **家庭**: 單身,與室友合租

## 個人簡介
小美是一位注重 CP 值的年輕上班族,喜歡在網路上比價和尋找優惠。她會仔細研究商品評價,確保每一筆消費都物超所值。

## 目標
1. 用有限預算買到品質好的商品
2. 找到最優惠的價格和折扣
3. 避免買到地雷商品

## 痛點
1. 不同平台價格差異大,比價很花時間
2. 優惠資訊分散,容易錯過好康
3. 擔心買到品質不好的商品

## 行為模式
- **購物頻率**: 每週 2-3 次
- **偏好裝置**: 手機 (80%) + 電腦 (20%)
- **購物時段**: 晚上 9-11 點
- **決策時間**: 通常會比較 3-5 個賣家才下單

## 引言
「我一定要看評價和比價,不然會覺得自己買貴了。」

## 技術能力
⭐⭐⭐⭐☆ (熟悉各種購物 App 和比價工具)

## 使用情境故事
週五晚上,小美躺在床上滑手機,看到朋友分享一款保養品。她立刻打開多個購物 App 比價,查看評價,加入購物車等待週末促銷。她會設定價格提醒,確保用最優惠的價格購買。
```

## 常見錯誤

❌ **錯誤**: 基於假設而非資料創建
✅ **正確**: 使用真實的研究資料支撐每個特徵

❌ **錯誤**: 創建太多人物誌(10+ 個)
✅ **正確**: 聚焦在 3-5 個主要人物誌

❌ **錯誤**: 只包含人口統計資料
✅ **正確**: 重點放在目標、行為和痛點

❌ **錯誤**: 創建後就不再更新
✅ **正確**: 定期檢視和更新人物誌
