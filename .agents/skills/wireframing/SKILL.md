# 線框圖設計技能

## 技能摘要

線框圖(Wireframe)是網頁或應用程式介面的低保真度視覺呈現,專注於內容佈局、資訊層級和功能流程,而不涉及顏色、字型等視覺設計細節。它是設計流程中的重要溝通工具。

## 適用情境

- 概念發想和快速迭代階段
- 與團隊討論介面結構時
- 在投入高保真設計前驗證想法
- 向利害關係人展示初步構想時

## 輸入資訊

- 頁面目標與核心任務
- 必要功能與內容區塊
- 使用者流程或導航結構
- 平台尺寸需求
- 需要溝通或驗證的重點

## 預期產出

- 線框圖範圍與層級規劃
- 主要版面與區塊配置
- 基本互動標註
- 不同保真度的建議做法
- 可供討論與迭代的初版方案

## 觸發提示

- 使用者提到「線框圖」、「wireframe」、「頁面草圖」、「低保真」、「版面配置」
- 任務需要先快速確認畫面結構與內容優先順序
- 任務需要在正式視覺設計前先討論頁面骨架

## 工作流程

### 1. 定義目標

**明確頁面目的**
```markdown
頁面目標範例:
- 頁面: 產品詳情頁
- 主要目標: 讓使用者了解產品並加入購物車
- 次要目標: 展示相關產品推薦
- 成功指標: 加入購物車轉換率
```

**列出必要元素**
- 導航列
- 產品圖片
- 產品名稱和價格
- 產品描述
- 規格選擇
- 加入購物車按鈕
- 相關產品

### 2. 繪製草圖

**紙筆快速草圖**
```markdown
優點:
✓ 速度最快
✓ 容易修改
✓ 適合團隊腦力激盪
✓ 降低執著於細節的風險

工具:
- A4 白紙或方格紙
- 鉛筆或黑筆
- UI 模板紙 (可選)
```

**數位工具繪製**
```markdown
推薦工具:
- Figma (協作友善)
- Sketch (Mac 專用)
- Balsamiq (低保真專用)
- Whimsical (快速簡單)
- Excalidraw (手繪風格)
```

### 3. 確定佈局

**常見佈局模式**

**F 型佈局**
```
[Logo]  [導航列]
[大標題]
[內容內容內容]
[內容] [側邊欄]
[內容] [側邊欄]
```

**Z 型佈局**
```
[Logo] ----------> [CTA按鈕]
       ↘
[特色內容]
       ↘
[詳細說明] -----> [註冊表單]
```

**卡片式佈局**
```
[卡片1] [卡片2] [卡片3]
[卡片4] [卡片5] [卡片6]
```

**柵格系統**
```markdown
常用柵格:
- 12 欄柵格 (最常見)
- 8 欄柵格 (平板)
- 4 欄柵格 (手機)

間距:
- 欄間距: 20-30px
- 外邊距: 20-40px
```

### 4. 標註說明

**互動標註**
```markdown
[按鈕]
→ 點擊後: 開啟彈出視窗
→ 狀態: 預設 / Hover / 點擊 / 禁用

[下拉選單]
→ 選項: 選項A, 選項B, 選項C
→ 預設值: 請選擇

[輸入框]
→ 提示文字: 請輸入電子郵件
→ 驗證: 必填,格式檢查
→ 錯誤訊息: 請輸入有效的電子郵件
```

**內容說明**
```markdown
[圖片區塊]
→ 尺寸: 800x600px
→ 內容: 產品主圖
→ 替代文字: 產品名稱

[文字區塊]
→ 標題: H1, 32px
→ 內容: 2-3 段落
→ 字數: 約 150 字
```

### 5. 團隊審查

**審查檢查清單**
```markdown
□ 資訊層級是否清晰?
□ 主要 CTA 是否明顯?
□ 導航是否直觀?
□ 內容佈局是否合理?
□ 響應式設計考慮?
□ 無障礙性考慮?
□ 與品牌一致性?
```

### 6. 迭代優化

**收集回饋**
- 與設計師討論視覺可行性
- 與開發者討論技術可行性
- 與產品經理確認功能完整性
- 與使用者測試可用性

**快速調整**
- 根據回饋立即修改
- 繪製多個版本比較
- 不要過早追求完美

## 最佳實踐

1. **保持簡單**: 使用灰階和基本形狀
2. **專注功能**: 專注於功能和內容,而非視覺美感
3. **清楚標示**: 標示清楚互動元素和狀態
4. **保持一致**: 保持一致的元件使用
5. **快速迭代**: 快速迭代,不要過早追求完美
6. **真實內容**: 使用真實內容而非 Lorem Ipsum
7. **考慮響應式**: 繪製不同螢幕尺寸的版本

## 線框圖保真度層級

### 低保真 (Lo-Fi)
```markdown
特徵:
- 手繪或簡單方框
- 無細節
- 快速草圖

適用:
- 初期概念發想
- 快速腦力激盪
- 多方案比較
```

### 中保真 (Mid-Fi)
```markdown
特徵:
- 數位工具繪製
- 有基本佈局
- 灰階呈現

適用:
- 與團隊溝通
- 使用者測試
- 開發參考
```

### 高保真 (Hi-Fi)
```markdown
特徵:
- 接近最終設計
- 有真實內容
- 可能有顏色

適用:
- 最終確認
- 客戶提案
- 開發交付
```

## 常見元素符號

```markdown
文字內容:
─────── (標題)
....... (段落文字)

互動元素:
[按鈕]
[_____] (輸入框)
[▼] (下拉選單)
□ (核取方塊)
○ (單選按鈕)

媒體:
[IMAGE] (圖片)
[▶] (影片)
[🔊] (音訊)

圖示:
☰ (選單)
🔍 (搜尋)
🛒 (購物車)
❤ (收藏)
⚙ (設定)
```
